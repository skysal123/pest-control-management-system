  Slider" effect.

  Instead of a standard grid or scroll, the services are now presented as a deck
  of cards that overlap each other, creating a 3D depth effect.

  Key Features of the New Design:

  1. Overlapping Stack: The cards are layered using z-index and transform: 
     scale(). The first card is fully visible, and the cards behind it are
     slightly smaller and shifted downwards, making it obvious to the user that
     more options are hiding behind.
  2. Interactive "Swipe" Action: When a user clicks a card, it triggers a smooth
     exit animation (sliding out to the right and rotating) and then
     automatically moves to the bottom of the deck.
  3. Modern Visuals:
     - Circular icons for a softer, cleaner look.
     - Smooth CSS transitions (cubic-bezier) for a professional feel.
     - Perspective rendering for actual 3D depth.

  How it works for the user:
  - They see the first cleaning service (e.g., Commercial Cleaning).
  - They can see the edges of the other cards beneath it.
  - Clicking the top card "swipes" it away, revealing the next service in the
    stack.
